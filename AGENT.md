## 3. Invariants & Domain Rules (Never Violate)

### 1. Mandatory Persistence Commit (`sendcmd 1 DB save`)
* Executing `sendcmd 1 DB set [Table] [Row] [Field] [Val]` modifies only the in-memory RAM database.
* Changes are **silently lost on reboot** unless followed by `sendcmd 1 DB save`.
* Any script or instruction that modifies NVRAM tables must explicitly call `sendcmd 1 DB save`.

### 2. Zero Hardcoded Personal Data
* Never commit or print real subscriber credentials, phone numbers, SIP passwords, live MACs, or GPON serials.
* All examples, tests, and documentation must use sanitized placeholders:
  * Phone numbers: `+9140XXXXXXXX`
  * GPON Serial: `ZTEGxxxxxxxx` / `5A544547xxxxxxxx`
  * SIP Proxy / IP: `10.232.xxx.xxx`
  * Passwords: `<extracted_md5_password>`

### 3. Dynamic Network Routing Detection
* Never hardcode client interface names (`eth0`, `wlan0`).
* Use dynamic routing queries (`ip route get <target_ip>`) to resolve the active interface and its corresponding hardware MAC address.

### 4. Router BusyBox Utility Limitations
* The target router runs a stripped-down BusyBox (`v1.17.2`).
* Do **NOT** assume utilities like `head`, `tail -n`, `strings`, `column`, `jq`, or `grep -P` exist on the router shell.
* Always pull raw command output over Telnet and parse it on the client side in Python.

### 5. Factory Session Management
* The `/webFac` endpoint requires an explicit reset sequence (`SendSq.gch`) before negotiating new challenges.
* The Telnet credentials generated by `FactoryMode.gch?mode=2` are temporary per-session tokens.

### 6. Safety & Laser Hazard Notice
* Whenever creating or editing fiber or ONT documentation, preserve the Class 1 invisible infrared laser radiation warning (1310/1490 nm).
